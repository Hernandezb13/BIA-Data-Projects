# 🛒 Saving Superstore — Data Visualization Project (Tableau)

## 📌 Project Overview

As part of the **TripleTen Business Intelligence program**, I was hired as a consultant to help the Superstore analyze its operations and improve profitability to avoid bankruptcy. Using Tableau, I explored profit trends, return rates, and advertising opportunities. This project involved building a series of visualizations and dashboards that answer business-critical questions and deliver actionable recommendations.

## 📊 Project Breakdown

### Part 1: Profits & Losses

- 🔹 **Top Profit Centers**:
  - **Accessories**, **Copiers**, **Phones**

- 🔻 **Biggest Loss-Makers**:
  - **Tables**, **Supplies**, **Bookcases**

- ❌ **Products to Stop Selling**:
  - Identified 10 lowest-performing products by total profit (e.g., 3D Printers, IP Phones)

- ✅ **Recommendations**:
  - Double down on subcategories with consistent profit (e.g., Accessories)
  - Phase out loss-makers and review pricing or fulfillment strategies

---

### Part 2: Advertising Strategy

- 🗺️ **Top Performing State-Month Combos**:
  - **Indiana – April**
  - **Rhode Island – November**
  - **Vermont – December**

- 📈 **Visualization**:
  - Plotted average monthly profit by state
  - Estimated recommended ad spend using Return on Ad Spend (ROAS) logic

- 💡 **Recommendation**:
  - Allocate up to 20% of profit to advertising in high-return regions during key months

---

### Part 3: Returned Items Analysis

- 🔄 **Top Returned Products**:
  - 8 of the top 10 items had a **100% return rate**
  - Examples: Wireless Speakers, 3D Printers, Specific Phones

- 👤 **Customers with High Return Rates**:
  - Highlighted top 10 customers, with some averaging return rates near **1.0**

- 🗺️ **Geographic Return Trends**:
  - **Utah** had the highest return rate
  - **Vermont** had the highest average profit

- 📉 **Profit vs. Return Rate**:
  - Built visuals comparing return rate and profit by **state** and **shipping mode**

---

## 🧠 Key Insights

- Losses are concentrated in a few subcategories (e.g., **Tables**, **Machines**)
- Advertising should be targeted geographically and seasonally for maximum ROI
- Return rates are heavily skewed by certain products and customer behaviors
- States like **Utah** present high risk, while **Vermont** is high-reward

---

## ✅ Recommendations

- 🔍 **Product-Level**: Remove or review low-performing and high-return products
- 💸 **Ad Spend**: Target high-profit months in select states; cap spend at 20% of expected profit
- 📦 **Returns**: Flag and address high-return customers and items; investigate logistics for high-return states
