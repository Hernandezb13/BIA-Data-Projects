## 🎓 Project Context: TripleTen NYC Airbnb Analysis

- 🏫 **Student Role**: Junior Business Intelligence Analyst at TripleTen
- 📍 **Objective**: Guide a client on which Manhattan property types to invest in using Airbnb rental data
- 📁 **Provided Data**: `listings` and `calendar` sheets from the NYC Airbnb dataset
- 📊 **Primary Tasks**:
  - Identify attractive neighborhoods and property sizes using `number_of_reviews_ltm`
  - Estimate revenue for top listings using availability and adjusted pricing
- 🧹 **Data Cleaning**:
  - Document all data prep steps in a separate sheet
  - Preserve a copy of raw data before cleaning
- 📈 **Analysis Requirements**:
  - Create pivot tables to evaluate rental activity and revenue
  - Use conditional logic and `SUMIF()` to estimate monthly and annual revenue
  - Add `top_listing` and `revenue_earned` columns to facilitate filtering
- ✅ **Deliverables**:
  - Cleaned dataset
  - Revenue ranking pivot tables
  - Final report with recommendations based on insights
