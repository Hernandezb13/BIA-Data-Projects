- 🏫 **Student Role**: Junior Business Intelligence Analyst at TripleTen
- 📊 **Objective**: Identify success factors for Shopify apps using scraped public data
- 📁 **Provided Dataset**: `shopify.xlsx` with four tables (`apps`, `apps_categories`, `categories`, `reviews`)
- 🧰 **Tools Used**: Power BI (.pbix), DAX, data modeling
- 🧪 **Tasks**:
  - Create 3 report pages: App Landscape, Reviews, and App Reviews
  - Build visualizations for each major analysis question
  - Write and apply DAX formulas to create calculated columns
  - Establish data relationships using Power BI's model view
- 📸 **Submission Requirement**:
  - Take full-screen screenshots of each completed visualization
  - Submit a `.pbix` file with all visuals and calculations included
- 🧠 **Skills Demonstrated**:
  - DAX expressions
  - Data modeling (many-to-one relationships)
  - KPI Cards, Line Charts, Scatterplots, and Bar Charts in Power BI
  - Business insight development and stakeholder-focused visualization
