## 📚 Project Context: TripleTen Business Analytics Program

- 🏫 **Role**: Junior Data Analyst (student simulation at TripleTen)
- 📊 **Objective**: Analyze raw e-commerce event logs and convert them into meaningful business metrics
- 🗂️ **Data Source**: Provided Google Sheets file with `raw_user_activity` tab
- 📈 **Key Tasks**:
  - Build a 3-stage **conversion funnel** (views → cart → purchases)
  - Prepare purchase data for **cohort analysis**
  - Calculate **monthly retention rates**
  - Summarize results and document analysis for executives
- 🧮 **Technical Skills Applied**:
  - Advanced **Google Sheets** functions (`VLOOKUP`, `TEXT`, `DATEDIF`)
  - Creation of **Pivot Tables**
  - Spreadsheet formatting and layout best practices
- 📅 **Timeframe**: Completed during **Sprint 3** of the program
- ✅ **Deliverables**:
  - Structured spreadsheet with analysis and summaries
  - Final PDF submission demonstrating analytical insights
